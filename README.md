# Shabbat at Home

Create a minimal placeholder project for a Hebrew right-to-left website called "שבת בבית".

Build ONLY one placeholder home page:
- <html dir="rtl" lang="he">
- A centered heading "שבת בבית" and one line of text "בקרוב".
- Warm off-white background #FAF8F3, heading color #1F3A5F. Fonts: Frank Ruhl Libre for the heading, Assistant for body (Google Fonts).

Important constraints:
- Do NOT enable Lovable Cloud, a database, authentication, storage or any backend. We will connect our own Supabase project later.
- Do not add any other pages, features, components or sample data.
- Keep Lovable's default project structure unchanged; development will continue from the GitHub repository.

This project was built with [Lovable](https://lovable.dev).
